# Local inputs only

Place only software you have the right to use here, or supply paths outside the repository. This folder's contents are ignored except this README.

- `user.rom`: optional native build input; supported ROM format described in docs/BUILD.md.
- `user-system-disk.img`: optional raw disk supplied by you.
- `touch_cal.json`: your screen's six affine calibration coefficients.

No input files are supplied, downloaded or licensed by this project. Owning a physical machine or receiving a download link does not automatically grant permission to redistribute its ROM/system/game files. Local native build outputs embed the supplied ROM; keep those generated outputs private as well.
