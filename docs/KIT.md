## What kind of kit is it?

**Unassembled parts for a DIY project.** The buyer assembles the hardware, prepares a microSD card, builds/loads the software and calibrates the touchscreen using the English guides. It is not a preassembled or preconfigured Macintosh computer. Soldering is required if the supplied Pico/header configuration needs it; check the final listing before ordering.

You should be comfortable connecting boards with the correct orientation, copying files, following build commands, selecting a serial port and checking a firmware installation. You do not need to design a new application to try MacTouch, but source builds and software setup are part of this project.

## What you can learn

- Assemble a small microcontroller system with a screen, touch input and SD storage.
- Run and change compact MicroPython drawing, note and game applications.
- Explore how an early computer emulator adapts to limited RAM and a small SPI display.
- Use ChatGPT, Claude or another coding assistant to draft changes, understand logs and iterate on real hardware. Read the [example workflow](AI-WORKFLOW.md); physical checks and review remain part of the process.

## Software and demonstrated content

The open-source project is available independently of the planned kit under its component licenses. **No Macintosh ROM, Apple operating system, Finder/game collection or ROM-embedded emulator binary is included in the public source package.** Obtain any permitted guest software yourself and prepare it as described in the [installation guide](QUICKSTART.md).

The prototype screenshots illustrate particular working scenes. They do not guarantee that an arbitrary downloaded game, a `.sit` archive placed on SD or an AI-generated program will run on this device. The emulator provides 192 KiB guest RAM, no audio output and no USB-host keyboard/mouse support in this port.
