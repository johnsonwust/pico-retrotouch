## What is it?

Pico RetroTouch is a compact retro-computing learning project built around a Raspberry Pi Pico, a 2.8-inch SPI resistive touchscreen and microSD storage. Choose between a lightweight touch desktop and a native early Macintosh emulator environment.

The touch desktop includes drawing and patterned fills, zoom navigation, an SD gallery, notes with an on-screen keyboard, puzzles and small touch games. The emulator uses compatible guest software supplied by the user, with Fit, original-pixel 1x and Pan controls for the small display.

## Why build it?

It is an approachable scale for experimenting with physical computing: a few small files can change something you see and touch. Use ChatGPT, Claude or another assistant to understand the code, prototype a small application or interpret a serial log, then verify the change on the device. It is a learning platform for an iterative workflow, not a promise that hardware debugging is fully automatic.

## Buyer requirements

You assemble the parts, prepare the card, follow the source build/setup instructions and calibrate the touchscreen. A computer, USB data cable and the documented development tools are required. Check the final packing list for included accessories and whether header soldering is needed.

No Apple ROM, operating system, third-party game collection or ROM-embedded firmware is provided in the public source package. Users must obtain software they have the right to use. Dropping a `.sit` file on SD does not automatically install it. The current emulator has 192 KiB guest RAM and no audio output or USB-host keyboard/mouse support.
